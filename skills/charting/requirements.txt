# Rendering dependencies for the charting skill.
#
# There are NO Python dependencies: every Python verb (init, settings, charts,
# themes, check, component, reports) is standard library only.
#
# Rendering needs Node 20+ with the pinned packages in package.json and a
# headless Chromium. `scripts/init.py init --install` runs the whole install
# once:
#
#     npm ci
#     node scripts/build.mjs
#     npx playwright install chromium
#
# After that, `render.py render` is fully offline. Without Node, the render verb
# fails fast with a `dependency_missing` error and every other verb still works.
